# Vertical Shooter (S/W engineering proj 1)

화면 아래쪽 플레이어 비행기를 좌우로 움직이며 총알을 쏘아, 위에서 내려오는 적을 맞히는 종스크롤 슈팅 게임.

## 실행 방법

- Python 3.10–3.13, pygame 2.x
  - Python 3.14 에서는 pygame 2.6.1 이 설치되지 않으니, 3.10–3.13 중 하나를 사용할 것.

```bash
pip install pygame
python main.py
```

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 좌우 이동 |
| Space | 시작 화면에서 게임 시작 / 게임 중 총알 발사 |
| R | 게임 오버 후 다시 시작 |
| Esc | 종료 (시작 화면에서도) |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 게임 루프 — 입력 처리, 갱신, 그리기, 점수·생명·게임 오버 |
| `entities.py` | 그림 불러오기(`load_frame`), 배경(`Background`), 스프라이트 클래스 — `Player`, `Bullet`, `Enemy` |
| `settings.py` | 화면 크기·속도·색 같은 상수 |
| `assets/` | 그림 — ansimuz CC0 픽셀 아트 (출처: `assets/CREDITS.md`) |
| `AI_USAGE.md` | 생성형 AI 사용 기록 |

- [x] F1 플레이어 이동 - 왼쪽, 오른쪽 방향키를 사용해서 플레이어를 이동시키고, 화면 밖으로 나가지 않도록 위치를 제한함.
- [x] F2 총알 발사 - Space키를 누르면 총알이 위쪽으로 발사되고, 총알이 화면 위로 완전히 벗어나면 제거됨
- [x] F3 적 명중과 점수 - 총알과 적이 충돌하는지 확인하고, 충돌한 경우 충돌한 총알과 적, 둘 다 제거함. 적 한 마리당 10점을 획득하고 현재 점수를 화면에 표시함.
- [x] F4 피격과 게임 오버 - 플레이어가 적이랑 충돌하거나 적이 화면 아래로 지나가면 생명이 감소한다. 생명이 0이하가 되면 게임을 종료하고 GAME OVER와 현재 점수를 표시한다. 
- [x] F5 재시작과 최고 점수 - 최고 점수를 highscore.txt에 저장하고 게임을 다시 실행할 때 불러오도록 구현했다. 게임 오버 화면에 현재 점수, 최고 점수, 재시작 방법을 표시하고 R키로 새로운 게임을 시작할 수 있도록 함.
